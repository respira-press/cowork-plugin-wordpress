# Respira Skills for Cowork

This folder contains the four core Respira skills that auto activate inside Cowork:

- `wordpress-editing-safety/`: snapshot, validation, rollback awareness.
- `page-builder-detection/`: picks the right approach per builder.
- `multi-site-context/`: manages multi site agency workflows.
- `respira-workflow/`: overall posture and visibility.

Each skill is a folder containing a `SKILL.md`. Claude reads the `description` in the frontmatter and auto activates the skill when the conversation matches.

The complete Respira Skills catalog (26 skills covering migrations, accessibility, design systems, integrations, niche builder workflows) is at:

https://github.com/respira-press/agent-skills-wordpress

For agencies and power users, install the full catalog directly through Cowork's plugin manager when you need it. The four skills bundled here cover the 80 percent path.
